# Cómo instalar Omero POS de escritorio

Guía rápida para instalar el Punto de Venta de Omero en tu computadora. El instalador
todavía no tiene firma digital, así que Windows y macOS muestran una advertencia la
primera vez que lo abrís — es un paso extra, no un error ni un virus.

## Windows

1. Descargá `omero-pos-setup.exe` y abrilo.
2. Windows puede mostrar una pantalla azul: **"Windows protegió tu PC"**.
3. Hacé clic en **"Más información"**.
4. Hacé clic en **"Ejecutar de todas formas"**.
5. Seguí los pasos del instalador (podés elegir dónde instalarlo).
6. Al terminar, queda un acceso directo en el Escritorio y en el Menú Inicio.

## macOS

1. Descargá `omero-pos.dmg` y abrilo.
2. Arrastrá el ícono de **Omero POS** a la carpeta **Aplicaciones**.
3. Al abrirlo por primera vez, macOS puede decir que **"está dañado y no se puede
   abrir"**. La app no está dañada: es porque el instalador no tiene firma de Apple.
4. Para abrirlo: mantené presionada la tecla **Control** y hacé clic sobre el ícono
   de la app (o clic derecho) → elegí **"Abrir"** → confirmá **"Abrir"** en el
   cuadro de diálogo que aparece.
   - Si no aparece esa opción: **Configuración del Sistema → Privacidad y
     Seguridad**, bajá hasta el aviso sobre Omero POS y tocá **"Abrir de todos
     modos"**.
5. Las próximas veces se abre normal, con doble clic.

## ¿Por qué pasa esto?

El instalador todavía no tiene certificado de firma de código. Esto no afecta el
funcionamiento de la app — solo hace que el sistema operativo pida una confirmación
extra la primera vez que se abre.
